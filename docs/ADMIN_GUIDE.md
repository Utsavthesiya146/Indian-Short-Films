# 🛠️ Admin Dashboard & Moderation Guide

## Accessing the Admin Dashboard
Navigate to `/admin` on the Web Application.

## Key Management Modules
1. **Overview Dashboard (`/admin`):** Live counts of Users, Films, Submissions, Views, Reviews, Reports, and language breakdown.
2. **Film Catalog (`/admin/films`):** Toggle Featured spotlight status, Trending ranking, or archive films.
3. **Submissions Queue (`/admin/submissions`):** Approve submitted films for immediate catalog publishing or reject with mandatory rejection feedback.
4. **Content Moderation (`/admin/reports`):** Inspect user reports for copyright, abusive speech, or spam and remove flagged content.
